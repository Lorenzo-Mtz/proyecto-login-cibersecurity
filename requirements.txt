# MFA por TOTP (WBS 4.3).
#
# pyotp implementa el RFC 6238. Esta aqui por R4: usar una libreria TOTP
# probada en lugar de programar el algoritmo desde cero.
#
# qrcode genera el codigo de aprovisionamiento. Se usa su factory SVG, NO el
# PNG: el PNG exige Pillow, una libreria de procesamiento de imagenes completa
# (decodificadores de JPEG, TIFF, WebP y demas, buena parte en C), para
# dibujar cuadritos negros en una reticula. El SVG no necesita nada extra.
# Quien quiera "mejorar" el QR pasandolo a PNG estaria agregando Pillow a la
# cadena de suministro para siempre: a cada revision de R6 y a cada corrida de
# pip-audit de 4.5.5. Nota: qrcode arrastra colorama en cualquier caso (es
# para su CLI), asi que si aparece en pip-audit, de ahi viene.
